# Voice latency and VRAM benchmark (2026-10)

Tool: `voice-bench` (`crates/atc-voice/src/bin/voice-bench.rs`), built with `--release`.

```
cargo build --release -p atc-voice --features whisper,piper --bin voice-bench
./target/release/voice-bench --whisper models/whisper/<model>.bin \
  --piper-config config/voices.toml --runs 10
```

Hardware: AMD Radeon RX 7900 XT (20 GiB VRAM, `card1`; the iGPU `card0` is ignored), whisper.cpp Vulkan backend.
VRAM is read from `/sys/class/drm/card*/device/mem_info_vram_used` on the card with the largest `mem_info_vram_total`.

Method: 3 warm-up runs excluded, then 10 timed runs; median and p95 (nearest rank).
STT input: Piper (ground voice) synthesis of "Krakow Ground, Sierra Alpha Bravo, request taxi" (about 3.4 s natural), resampled to 16 kHz and padded/trimmed to exactly 3 s, with the aviation `initial_prompt`; language forced to `en`.
TTS input: dispatcher line (tower voice, about 10 s of audio): "Sierra Papa Alpha Bravo Charlie, Krakow Ground, taxi to holding point Alpha one via Alpha, runway two five, QNH one zero one three."

## Without X-Plane (desktop session only)

| model | load ms | STT median ms | STT p95 ms | VRAM before MiB | VRAM loaded MiB | VRAM peak MiB | model VRAM (peak - before) MiB |
|---|---|---|---|---|---|---|---|
| ggml-large-v3-turbo-q5_0 | 161 | 157 | 169 | 1555 | 2102 | 2473 | 918 |
| ggml-small.en-q5_1 | 77 | 78 | 79 | 1576 | 1757 | 2015 | 439 |

Transcripts: large-v3-turbo "Krako Ground, Sierra Alpha Bravo, request taxi." (misspelled the station name); small.en "Krakow Ground, Sierra Alpha Bravo, request taxi" (exact). Large-v3-turbo with the earlier, longer phrase also misheard the tail, so it is not clearly more accurate on this synthetic English audio.

Piper TTS (tower voice, about 10 s of speech): median 415 ms, p95 433-456 ms (consistent across both runs). Piper runs on CPU as a subprocess, so it does not add VRAM.

Total VRAM is 20480 MiB; the baseline desktop use is about 1.6 GiB. With the large model resident at peak (2.5 GiB) about 17.5 GiB remain free.

## Default model choice

Rule: large-v3-turbo if STT p95 <= 1.2 s and X-Plane + Whisper leaves >= 6 GiB of VRAM free; otherwise small.en (Polish/Russian would then need multilingual small).

**PROVISIONAL: ggml-large-v3-turbo-q5_0.** STT p95 is 0.17 s (far under 1.2 s), and without X-Plane, 17.5 GiB are free with the model loaded.
